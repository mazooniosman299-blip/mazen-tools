# Mazen Tools

أدوات عربية وإنجليزية للصور وPDF والنصوص، تعمل داخل المتصفح دون رفع ملفات المستخدم.

الموقع الحالي: https://mazentoolsfree.mazooniosman299.workers.dev/

المستودع الرسمي: https://github.com/mazooniosman299-blip/mazen-tools

## التشغيل الآلي

التحديثات البرمجية على main تمر بالاختبارات ثم تنشر إلى Worker الحالي mazentoolsfree. يحفظ المسار توزيع الإصدار السابق، ويطابق الملفات العامة مع البناء ويختبر الأدوات بعد النشر، ويتراجع عند فشل التحقق ما لم يوجد نشر أحدث. لا ZIP يومي ولا تغيير للرابط. التعديلات التوثيقية البحتة قد تستخدم [skip ci] دون المساس بالتطبيق المنشور.

نجح النشر والتحقق العام بالفعل: [إيصال النشر](https://github.com/mazooniosman299-blip/mazen-tools/actions/runs/39935719918). ونجح تشغيل [الصيانة المستقلة](https://github.com/mazooniosman299-blip/mazen-tools/actions/runs/39936101698).

تشمل الفحوص اليومية Sitemap والصفحات وrobots وملف Google. تشمل الفحوص الأسبوعية الأدوات والتنزيلات والقياسات الاصطناعية للأداء. التقارير متاحة في GitHub Actions لمدة14 يوماً؛ القياسات الاصطناعية ليست زيارات أو أرباحاً.

[تفاصيل الصلاحيات والجدولة والاسترجاع والقياس](AUTOMATION-ar.md).

## الحالة الإعلانية والخصوصية

الإعلانات والتحليلات معطلة. ملف إثبات الملكية الأصلي محفوظ. وصول Google للفهرسة وقبول AdSense والإيرادات أمور منفصلة لم تُؤكد عبر الحسابات. لا مفاتيح أو بيانات خاصة في المستودع؛ توضع الاعتمادات في GitHub Secrets فقط.
